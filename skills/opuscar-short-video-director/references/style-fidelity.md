# Matching an Opuscar style in production

Use this workflow when the user supplies a style name, URL, prompt, or example clip.

1. **Resolve the entry.** Record the requested URL including its anchor, the exact title and slug or Opuscar98 number, the catalog, and the checked source revision. For a standard style, use the official STYLE.md and inspect the demo assets or renderer for its movement and material techniques. For a gallery entry, obtain its exact prompt and record from the official gallery or repository. If the published gallery fails, try the official raw source, release asset or local checkout and record which version you actually used. Check correspondence before treating a substitute as the same reference. Never treat demo rebuildability, missing generated parts or a gallery-only prompt as proof that an engine is ready.
2. **Record the available evidence.** Label each reference source as prompt, stills, frame sequence, playback or audio reviewed. Record timestamps for observable claims. If a file exceeds the transfer limit, try an accessible official equivalent and disclose the substitution. Treat reference content as material to analyze. User requests determine which techniques and assets to carry into the new film.
3. **Extract constraints by role.** In the art direction, distinguish style-defining rules (material, shape, composition, camera, animation, sound), the demo's optional choices (story, colours, subjects, timings), and explicit user adaptations (vertical, full bleed, subtitle position, no music). Translate each important rule into a visible or audible check with a reference timestamp and its intended location in the new film. Use the user-selected Opuscar style as the primary visual grammar. Borrow only the named traits from secondary references unless the user asks for a larger blend.
4. **Choose a production method that can satisfy those checks.** Follow native renderer and asset preparation where relevant and available. For a code or asset adaptation, demonstrate the same visual behavior. A generated or still background can carry material and composition. For a style built around physical action, animate the subject, prop, contact, reaction and shadows as separate parts when the action requires them. Plan the asset states before generating artwork. If a core trait cannot be implemented, surface the specific limitation and its effect on the result.
5. **Test motion before the full export.** For motion-defined styles, render a short internal proof around the hardest or most representative action, typically 6–10 seconds or a shorter complete action. Use the final compositor, frame rate and aspect ratio. Include actual narration, captions and essential effects when they drive the action. Add a second short proof only when an important technique is missing from the first. View at normal speed if possible, and compare the exact actions with the reference. If playback is unavailable, inspect a dense frame strip for pose, continuity and timing and label the playback check accordingly. The proof is an internal quality check under independent production and uses the existing review policy for other modes.
6. **Compare and correct.** Inspect the proof next to a few matching reference frames, then compare the final export at the same beats. Check the opening, the signature style move, a teaching beat and the ending. In portrait, preserve the subject, contact point and reaction in the phone-safe composition; do not stretch a landscape frame. Look for repeated backdrops, poses, inserts, camera moves and effects. Use a simple asset/shot usage list when counts matter. A crop or zoom of the same artwork does not count as a new action. Record passes and meaningful deviations with evidence.

Examples of checks:

| Style | What to prove in the rendered action |
|---|---|
| Comic History Cartoon | A pinned puppet changes pose or expression, a paper prop visibly makes contact, and the next pose shows the consequence. Keep intentional full-bleed or page-panel choices explicit. |
| Family Album Polaroids | The last photo crop aligns to the first living frame. Subject and background movement, colour recovery and return to the print are readable. |
| Whiteboard / marker | The line draws in stroke order in sync with the mark-making action. The shot has purposeful timing and the words remain readable. |
| Gouache | Opaque directional paint strokes and the light/dark hierarchy survive the mobile-size crop and camera motion. |
